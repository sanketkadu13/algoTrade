📖 How the Owl Method works
Premise. The residual move after gap-open + early-session churn rarely exceeds ±1.5%. Selling 1.5%-OTM CE+PE collects theta against that bounded intraday move.

Daily setup (executed every trading day except monthly expiry):
  1. At the configured entry time, fetch NIFTY spot LTP (live, not the day's open).
  2. Compute CE strike = ceil(Spot × 1.015 / 50) × 50 (round up — strike at or above the 1.5% target, so the call is always at least 1.5% OTM).
  3. Compute PE strike = floor(Spot × 0.985 / 50) × 50 (round down — strike at or below the target, so the put is always at least 1.5% OTM).
  4. SELL 1 lot CE + 1 lot PE of the current monthly expiry.
Note: the original transcript anchors strikes off the open price because his backtests need a fixed historical reference. For live execution we use CMP at trigger so the buffer reflects where price actually IS when you enter, not where it opened hours ago.
Stop-loss + exit. ₹2,000 per leg (independent). If a leg hits SL, close only that leg; the other keeps running until the configured exit time. If neither leg hits SL, both close at exit time. Worst-case daily loss ≈ ₹4,000 (both legs SL'd).

Lot size. NIFTY lot is currently 65. At 65/lot, ₹2,000 SL ≈ 30.8 pts on the option premium — a tight intraday tolerance. Consider widening if your back-test shows excess whipsaw.

Margin. Naked option selling — one NIFTY strangle needs ~₹2.5–3 lakh SPAN+exposure margin. The dashboard does not pre-check margin; Kite will reject if insufficient.

Paper mode. Default ON. Records simulated fills at the live LTP at trigger; tracks fake P&L using real ticks. Flip "Paper trade" off only when you're confident in the parameters.

Skip-expiry-day rule. The strategy never enters on monthly expiry day — premiums collapse fast and the risk asymmetry breaks down.

Original strategy: Mahesh Chandra Kaushik's "Ullu Vidhi" (owl method). The 1.5% offset, ₹2,000 per-leg SL, and one-leg-keeps-running rule are his. Implementation tailored to current NIFTY lot size + Kite API constraints.

🛡 MIS Pre-Square Safety
Kite RMS auto-squares MIS (intraday) positions at 15:20 IST. If your SL/target hasn't fired by then, RMS exits at whatever the market gives — you lose price control. This safety net force-exits running MIS strategies a few minutes earlier so you pick the exit price, not Kite.

📱 Telegram Alerts
Hook up a Telegram bot and the dashboard will DM you on entries, exits, trailing-SL hits, IP changes, EOD summaries, and more. You can also send commands back (/status, /positions, /exit, etc.) — full list in /help once connected.
📖 How to set this up (one-time, ~3 minutes)
Step 1 — Create your bot
  1. Open Telegram and message @BotFather.
  2. Send /newbot.
  3. Pick a display name (e.g. "Kite Monitor") — shown in chat headers.
  4. Pick a username — must end in bot (e.g. my_kite_alerts_bot).
  5. BotFather replies with a token like 1234567890:AAH•••••••••. Copy it — that's the Bot token field above.
Step 2 — Find your chat ID
  1. In Telegram, search for your new bot by username and open the chat.
  2. Tap Start (or send any message). This is required — bots cannot DM users who haven't initiated the chat first.
  3. Now message @userinfobot with /start. It replies with your numeric ID — that's the Chat ID.
  4. Group chats: add the bot to the group, send any message, then visit https://api.telegram.org/bot<token>/getUpdates in a browser — look for "chat":{"id":-100...}.
Step 3 — Save + test
  1. Paste the token and chat ID above, hit Save.
  2. Hit Send test message — you should get a DM within a second.
  3. If the test fails: most common cause is forgetting Step 2.2 (you must press Start on your bot first). Other causes the API returns clearly: bad token = "Unauthorized", wrong chat_id = "chat not found".
Step 4 — Try the bot
Once connected, send /help to your bot to see all commands. A few of the most useful:
  • /status — running strategies + today's P&L
  • /positions — live Kite positions
  • /exit <sid> — square off a strategy (asks for confirmation)
  • /pause / /resume — toggle auto-entry for the day
⚠ Security notes
• All credentials live in this instance's .env (chmod 600) and never appear in logs.
• Bot token: anyone with it can DM as your bot. @BotFather → /revoke to rotate.
• The bot only accepts commands from the chat ID you save here.
• Kite API secret + TOTP secret: rotate at developers.kite.trade if compromised.
